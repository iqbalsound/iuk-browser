# Building IUK Browser from Firefox source (phase 2)

IUK Browser is Firefox ESR source plus: (1) a branding directory generated by `branding/apply_to_source.py`,
(2) a `mozconfig`, and (3) the distribution layer (policies + the bundled sync/vault extension).
Using the *unofficial* branding path means Mozilla's name, logo and update servers are not used, so the
binaries may be redistributed.

## Linux (DEB + RPM)

Requirements: ~40 GB free disk, 16 GB RAM (8 GB works but is slow), git, python3, curl, `nfpm`.

```bash
build/build-source.sh                         # latest ESR tag, produces dist/*.deb and dist/*.rpm
FIREFOX_REF=FIREFOX_153_7_0esr_RELEASE build/build-source.sh   # pin a version
SKIP_PACKAGE=1 build/build-source.sh          # stop after ./mach package
```

What it does: clones the ESR tag from `github.com/mozilla-firefox/firefox`, runs
`branding/apply_to_source.py` (copies `browser/branding/unofficial` to `browser/branding/iuk-browser`,
replaces **every** image at the original pixel size and rewrites strings), installs `build/mozconfig.linux`,
runs `./mach bootstrap`, `./mach build`, `./mach package`, then `packaging/build-bundle.sh`.

## Windows

Install [MozillaBuild](https://firefox-source-docs.mozilla.org/setup/windows_build.html), clone the same ESR tag,
then inside the MozillaBuild shell:

```bash
python3 /path/to/iuk-browser/branding/apply_to_source.py .      # needs: pip install -r branding/requirements.txt
cp /path/to/iuk-browser/build/mozconfig.windows mozconfig
./mach bootstrap && ./mach build && ./mach package
```
Then, on any machine with `7z`, `zip`, `unzip` and `makensis`:
```bash
SOURCE_BUILD=1 FIREFOX_ZIP=obj-iuk-browser/dist/firefox-*.win64.zip packaging/build-bundle.sh windows <version>
```

## Where the icons come from

| Place | Source file(s) |
|---|---|
| Window, taskbar, minimized window, alt-tab (Linux) | `default{16..256}.png` in the branding dir, plus `hicolor` icons and `iuk-browser.desktop` (`StartupWMClass=iuk-browser`) |
| `.exe`, taskbar, Start menu, jump list (Windows) | `firefox.ico`, `firefox64.ico`, `newtab.ico`, `newwindow.ico`, `pbmode.ico`, `VisualElements_*.png` |
| Documents (HTML/PDF file associations) | `document.ico`, `document_pdf.ico`, `content/document_pdf.svg` |
| About dialog / about: pages | `content/about-logo*.png/svg`, `about.png`, `about-wordmark.svg` |
| Private browsing | `PrivateBrowsing_*.png`, `about-logo-private*.png`, `pbmode.ico` |
| Installer | `wizHeader*.bmp`, `wizWatermark.bmp`, `stubinstaller/bgstub.jpg`, `msix/Assets/*` |
| Extension toolbar button and add-on manager | `extension/icons/*` |

All are drawn from `branding/src/*.svg`. Edit the SVGs, run `python3 branding/generate.py` and rebuild.
`branding/preview.png` shows every variant at real sizes. macOS-only files (`Assets.car`, `dsstore`) are left alone because macOS is not a target.

## Known caveats

- The internal binary is still called `firefox` (`MOZ_APP_NAME`); the launcher, desktop entry, window class, remoting name and window icon are IUK Browser. Task managers will show `firefox`.
- The User-Agent keeps its `Firefox/` token on purpose, for website compatibility.
- This pipeline was developed against the ESR 153 branding template and verified for file layout and image sizes, but the full compile was **not** run in the authoring environment. See `TODO.md` for the first-build checklist.
